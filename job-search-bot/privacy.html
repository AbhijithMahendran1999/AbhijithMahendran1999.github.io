Job Search Bot: privacy policy

Last updated 2 November 2026

Job Search Bot is a personal tool. Its only user is its developer, Abhijith Mahendran.

What it accesses

With the developer's own consent, it uses the Gmail API with the read-only scope (gmail.readonly) to read job-alert emails in one label of the developer's own mailbox.

What it does with the data

  • It extracts job titles, employers, locations and job links from those emails.
  • The results are stored only on the developer's own computer.
  • It never sends, changes or deletes email.
  • Data is never sold, shared, or transferred to anyone, and is not used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
